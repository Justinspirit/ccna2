EIGRP 
- The best dynamic routing protocol
- Administrative Distance of 90
- Cisco proprietary

EIGRP States
Hello 
Update 
Query 
Receive 
Acknowledge 

EIGRP recipes:
 • router eigrp ### AS
 • no auto-summary
 • network <directly connected> <wildcard mask>
 • same AS number advertises





OSPF Routing (Open Shortest Path First)
- Multi-Vendor Dynamic Routing Protocol 
- Link State Advertisement
- Implements Dijikstra Algorithm
- Administrative Distance of 110
- Advertised by AREA (area 0 is the backbone) 


OSPF States
Down
Init (Initiates)
Two-Way
Ex start
Exchange
Loading
Full

Recipe:
 router ospf <router-id>
 router-id <ip>
  network <directly conncted network> <wildcard DCN> area <number>


R4:
 conf t 
   router ospf 100
   router-id 4.4.4.4
   network 10.1.1.8 0.0.0.3 area 34
   network 4.4.4.4 0.0.0.0 area 34
end

BGP Routing (Border Gateway Protocol)
- Mostly used for WAN 
- Administrative Distance of 20
- Also used by ISP and Large Corporations

recipe for BGP:

router bgp <AS no.>
 bgp long-neighbor-changes
 neightbor <direct IP of next hop> remote-as # <AS no. of neighbor>
 network <network IP of this host>

R1

 router bgp 1

 neighbor 207.7.7.2 remote-as 2
 neighbor 209.9.9.3 remote-as 3
