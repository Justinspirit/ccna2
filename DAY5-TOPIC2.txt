IPV6 Addressing:
- IPv4 is 32bits vs IPv6 is 128bits
- IPv4 has 4 Octets (3dots) vs IPv6 has 7 (Colons)

ex. 1111:0123:0012:0001:abcd:0abc:9891:abcd

It allows zero-ommision
Continous zeroes can be eliminated, in hte place of full zeroes, simply use a double-colon(::)

Rule 1- leading Zero Ommision
before 1111: 0123: 0012: 0001: abcd: 0abc: 9891: abcd
after  1111: 123: 12: 1: abcd: abc: 9891: abcd

Rule 2 - Continous Zero Omission
before: 1111 : 0123 : 0000 : 0000: abcd : abcd : abcd :1000
after:  1111 :  123        ::      abcd : abcd : abcd :1000

another before : 1234:0000:0000:0000:abcd:0000:0000:0000
after:           1234        ::      abcd:  0 :  0 :  0

Rule 3 - Discontinous Zero Ommision 
before: 1111: 0000 : 0000 : abcd : 0101 : 0000 : 1230 : f00d
after:  1111:     ::        abcd : 101  :   0  : 1230 : f00d
